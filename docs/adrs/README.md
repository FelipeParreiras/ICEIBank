# Architecture Decision Records

ADRs registram decisões difíceis de desfazer ou que afetam várias partes do sistema.

## Estados

- Proposto
- Aceito
- Rejeitado
- Substituído por ADR-NNNN

## Convenção

Arquivos seguem `NNNN-titulo-curto.md`. Para alterar uma decisão aceita, crie outro ADR e marque o anterior como substituído.
