# Especificações

As especificações descrevem comportamento verificável sem impor detalhes desnecessários de implementação.

## Fluxo sugerido

1. Copiar `template.md` para um nome descritivo, como `contas.md`.
2. Definir objetivo, regras, contratos, erros e critérios de aceitação.
3. Relacionar ADRs que afetem a solução.
4. Atualizar o estado da especificação durante a entrega.

Nenhuma especificação funcional foi preenchida ainda; isso evita antecipar decisões durante a fase de configuração.
